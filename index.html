Catmoji
Computer Vision Full-Stack

A web application that detects and classifies the emotional state of a cat from a photo — recognising four emotions: alarmed, angry, calm, and pleased. Built end-to-end from model training to deployment.

Python Flask PyTorch ResNet18 OpenCV HTML/CSS/JS

How it works

The backend is a Flask server that accepts an uploaded image and runs a multi-step inference pipeline. First, a Haar Cascade classifier (haarcascade_frontalcatface_extended.xml) detects the cat's face and crops the region. The crop is then resized, normalised, and converted to a tensor before being fed into a fine-tuned ResNet18 model. The predicted emotion label is returned to the frontend and displayed to the user.

Architecture

Two pages: index.html for image upload and results.html for displaying the prediction. The frontend communicates with the Flask API via HTTP, keeping the UI clean and accessible to non-technical users.

Research component

Conducted a comparative study between ResNet18 and MobileViT on the cat emotion recognition task, evaluating accuracy, inference speed, and generalisation. ResNet18 was selected for deployment based on its consistent training results.

Face Emotion Recognition
Deep Learning Research

An AI project benchmarking deep learning architectures for facial expression recognition, implemented in Python with Jupyter Notebook for interactive experimentation and documentation.

Python PyTorch ResNet18 MobileViT Jupyter Notebook

Overview

This project focuses on Computer Vision and Image Classification, comparing two architectures: ResNet18 — a classic convolutional neural network — and MobileViT, a lightweight vision transformer designed for resource-constrained environments. Both models were trained and evaluated on a labelled facial expression dataset.

Tech stack

Built entirely in Python within a Jupyter Notebook environment, leveraging PyTorch for model implementation and standard data processing libraries for preprocessing and augmentation pipelines.

Fitness App
Software Engineering Group Project

A health and fitness mobile application built as a software engineering group project. Helps users track their weight, calculate BMI, log daily exercises, discover healthy recipes, and self-diagnose symptoms through a questionnaire-based system.

MVC Architecture Agile Use Case Analysis Function Point Analysis

Key Features

BMI calculation from height and weight inputs; a weight tracking program with trend analysis that suggests exercises when weight increases or alerts the user if weight drops too rapidly; an exercise logger where users record sets and reps per session; a healthy recipe browser with step-by-step cooking instructions; and a symptom questionnaire that diagnoses potential illnesses and recommends treatments.

Architecture & Process

Built on an MVC (Model-View-Controller) pattern — the Model handles business logic (BMI formula, weight trend analysis, food and illness databases), the View renders charts, recipe lists, and result screens, and the Controller bridges user interactions with data flow. The team followed an Agile process model with daily standups and weekly milestone deliverables.

Engineering Depth

The project included formal software engineering artefacts: Use Case and Activity diagrams, a Class diagram, Use Case Point and Function Point effort estimation, a Risk Table, Cyclomatic Complexity analysis, and a full test case suite — demonstrating end-to-end software development methodology.
